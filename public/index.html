Avvio Rapido & Comandi Terminale

Istruzioni per eseguire e distribuire l'addon nel tuo ambiente

LOCALE Esecuzione con Node.js & npm 
# 1. Installa le dipendenze
npm install

# 2. Avvia il server addon (Linux / macOS / PowerShell)
PUBLIC_BASE_URL=http://localhost:7000 npm start

# Oppure su Windows CMD:
set PUBLIC_BASE_URL=http://localhost:7000 && npm start
CLOUD DEPLOY Distribuzione su Render / Railway / Docker 
# Variabili d'ambiente richieste per Cloud:
PORT=7000
PUBLIC_BASE_URL=https://tuo-addon.onrender.com

# Build & Run con Docker:
docker build -t stremio-addon .
docker run -p 7000:7000 -e PUBLIC_BASE_URL=https://tuo-dominio.com stremio-addon

Guida Configurazione & Hosting Addon

Come funziona il portale con i tracker italiani:

  1. Tracker Italiani: abilita IlCorsaroViola, IlCorsaroNero, IlCorsaroBlu, TNTVillage, 1337x per indicizzare torrent in italiano.
  2. Provider Debrid: inserisci l'API Token di TorBox, RealDebrid, AllDebrid per sbloccare flussi in cache istantanea.
  3. Formattazione come da foto: i flussi sono generati con icone 🗳️, 📁, 💾, 🗣️ 🇮🇹 🇬🇧 e 🔗 💾 Tracker 👥 Seeders.
  4. Installazione con 1 click: clicca su "Installa su Stremio" o inquadra il QR Code con la TV.
